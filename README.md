# constructive-prehistory · 构造数学·前身故事（六篇生成史）

构造数学六条线的前置版本生成史：问题怎么问出来、判据怎么切下去、命运怎么落定。姊妹系列《构造数学·延伸篇》讲理论本身，本系列讲理论的诞生。

| 篇 | 章名（创立者原话） | 主角线 | 命运 |
|---|---|---|---|
| 01 | 一场没想清楚就开始的构造 | 三维比数→自发比数 | 升格 |
| 02 | 挖一头就通到根 | 原始涡几何→涡几何 | 反转 |
| 03 | 数是会动的 | 场域数学→密度数学+动层 | 裂变 |
| 04 | 字先于数 | 字学理论 | 追认 |
| 05 | 动数公理不完备只是特例 | 锚数 | 判例 |
| 06 | 进行时 | 双吸引子×耦合涡 | 进行时（开放式结局） |

主线一句话：**每条线的第一步都是一个问题，不是一篇论文。**
